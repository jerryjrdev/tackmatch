# TackMatch website

Privacy Policy, Terms of Use and Support pages for the iOS app **TackMatch: Saddle & Helmet Fit**, served by GitHub Pages:

- https://jerryjrdev.github.io/tackmatch/
- https://jerryjrdev.github.io/tackmatch/privacy
- https://jerryjrdev.github.io/tackmatch/terms
- https://jerryjrdev.github.io/tackmatch/support

Static HTML and CSS, no build step. The source lives in the app project's `site/` folder; deploy with `tools/deploy_site.sh` there.
